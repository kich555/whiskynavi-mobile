# Navi Sans

기존 웹의 `public/font/PretendardJPVariable.woff2`에서 400·500·700 축을 fontTools 4.67.0으로 인스턴스화하고 TTF로 변환했다. 글리프와 메트릭은 원본을 유지한다. 변환본의 기본 패밀리·PostScript 이름은 `Navi Sans` / `NaviSans-*`로 바꿨다. Expo에서는 NaviSans, NaviSansMedium, NaviSansBold 이름으로 로드한다.

원저작자와 라이선스는 [원본 프로젝트](https://github.com/orioncactus/pretendard)의 SIL Open Font License 1.1을 따른다. 전문은 LICENSE-Pretendard.txt에 있다. 이 글꼴은 독립 판매하지 않으며 WhiskyNavi 앱에 포함한다.
