# 모바일 내비게이션의 다섯 영역과 기본 진입 화면

기존 네이티브 하단 바의 다섯 영역을 홈·아카이브·스토어·커뮤니티·마이로 구성하고, 브랜드와 아카이브는 아카이브에, 예약과 상품은 스토어에, 공지·커뮤니티·소식은 커뮤니티에 묶는다. Android NativeTabs의 다섯 탭 제약 안에서 홈과 마이를 유지하고 브랜드·콘텐츠 발견성을 높이기 위해 예약·쇼핑을 합치며, 홈을 탐색으로 통합하거나 소식을 독립 하단 탭으로 만드는 대안은 채택하지 않는다. 사용자가 브랜드·예약·공지의 우선 노출을 명시했으므로 각 영역의 첫 진입은 이 화면들로 시작하고 같은 앱 실행 중 재방문은 마지막 선택 상태를 유지한다.

상태: 수락·구현 — 2026-10-25. 네이티브 실기기 검증은 별도다.
