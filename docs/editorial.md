# 스토리 이관

23편의 원고를 웹과 같은 src/data/editorial/library.json으로 제공한다. /stories 목록의 카테고리·검색, /stories/[slug] 읽기·목차·이미지 확대·공유·읽던 위치 재개를 구현했다. 기존 5개 하단 탭을 유지하며 스토리 목록은 커뮤니티의 네 번째 상단 탭으로 제공한다. `/stories` 공개 주소는 유지하고 상세는 기존 Stack에서 연다. 브랜드 메뉴의 진입 링크도 같은 탭으로 연결된다. 홈 최상단의 스토리 진입 링크는 제거했다.

이미지 참조 231건(고유 이미지 227개)은 로컬 WebP다. 400,000바이트 미만이며 앱 번들에 이미지를 포함한다. 로컬 이미지 확대 모달을 제공한다. 표는 가로 스크롤로 읽는다. 현재 원고는 칼럼 12편·증류소 11편이며 검토 중 원고는 없다. 작성 중/짧은 원고가 들어오면 검토 중으로 구분한다.

웹 저장소 scripts/editorial/sync-mobile.mjs에 이 저장소 경로를 넘겨 콘텐츠를 갱신한다. 관리자 편집·발행 및 자동 Notion 동기화는 연결하지 않았다. 네이티브 공유는 앱 딥링크를 사용한다. 읽던 위치는 기기에 저장하며 웹 미리보기에서는 현재 세션 메모리에만 유지한다.

검증: TypeScript·ESLint, 18개 파일 165개 테스트, iOS/Android/Web Expo 번들 생성과 배포 번들 검사 통과. 브라우저에서 카테고리 필터와 상세 읽기 화면을 확인했다. 실제 iOS/Android 기기 실행과 네이티브 공유 시트는 미검증이다.

사용자의 최신 선택에 따라 화면에서 CDN 사용을 중단했다. 이전 승인으로 완료된 원격 S3 파일은 이번 로컬 정리 대상이 아니다. 로컬 업로드 영수증은 삭제했다.

## 2026-11-01 콘텐츠 갱신

Notion 칼럼·증류소 컬렉션을 다시 읽어 웹과 같은 원문·이미지로 동기화했다. 기존 원고 22편은 공개 slug를 유지하고 sourceUrl만 새 Notion 페이지로 연결했다. 글렌오드 1편을 추가했으며 컬렉션에서 빠진 14편은 목록에서 제외했다. 빈 브런치 연재분 페이지는 노출하지 않았다. 독립병입자 원고·카테고리·전용 이미지는 후속 요청에 따라 삭제했다. 미사용 이미지 사본을 정리했고 새 이미지는 400,000바이트 미만 로컬 WebP다. 이전 검증 기록은 이 갱신 이후의 실제 단말 검증을 의미하지 않는다.

이번 콘텐츠 갱신 검증: TypeScript·Expo ESLint 및 스토리 단위 테스트 3개 통과. 웹과 모바일의 JSON 및 고유 이미지 227개의 바이트 일치를 확인했다. 이번 갱신에서는 실제 단말 실행과 네이티브 번들 생성은 다시 수행하지 않았다.

복구 자료·캐시 정리: 모바일에는 현재 사용 중인 이미지 227개만 있으며, 별도 스토리 원본·백업·다운로드 캐시는 없다. 웹의 과거 원문·백업·이미지 변환 캐시는 삭제했고 현재 콘텐츠 재생성용 원문과 이미지 매핑만 유지한다.

카테고리·색상 통일: 독립병입자 카테고리를 제거했고 해당 글은 더 이상 조회되지 않는다. 탭 밑줄·본문 링크 등 스토리 전용 연두색을 공통 colors.accent 흰색으로 교체했다.
