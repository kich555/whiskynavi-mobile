# 스토리 이관

37편의 원고를 웹과 같은 src/data/editorial/library.json으로 제공한다. /stories 목록의 카테고리·검색, /stories/[slug] 읽기·목차·이미지 확대·공유·읽던 위치 재개를 구현했다. 기존 5개 하단 탭을 유지하며 스토리 목록은 커뮤니티의 네 번째 상단 탭으로 제공한다. `/stories` 공개 주소는 유지하고 상세는 기존 Stack에서 연다. 홈·브랜드 메뉴의 진입 링크도 같은 탭으로 연결된다.

이미지 참조 235건(고유 이미지 230개)은 로컬 WebP다. 400,000바이트 미만이며 앱 번들에 이미지를 포함한다. 로컬 이미지 확대 모달을 제공한다. 표는 가로 스크롤로 읽는다. 원문 작성 중/짧은 원고 5개는 검토 중으로 구분한다.

웹 저장소 scripts/editorial/sync-mobile.mjs에 이 저장소 경로를 넘겨 콘텐츠를 갱신한다. 관리자 편집·발행 및 자동 Notion 동기화는 연결하지 않았다. 네이티브 공유는 앱 딥링크를 사용한다. 읽던 위치는 기기에 저장하며 웹 미리보기에서는 현재 세션 메모리에만 유지한다.

검증: TypeScript·ESLint, 18개 파일 165개 테스트, iOS/Android/Web Expo 번들 생성과 배포 번들 검사 통과. 브라우저에서 카테고리 필터와 상세 읽기 화면을 확인했다. 실제 iOS/Android 기기 실행과 네이티브 공유 시트는 미검증이다.

사용자의 최신 선택에 따라 화면에서 CDN 사용을 중단했다. 이전 승인으로 완료된 S3 파일은 삭제하지 않고 영수증만 유지한다.
