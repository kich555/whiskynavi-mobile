# S02: 탐색·이미지·로그인에서 사용자가 흐름을 제어하기

**Status:** ready-for-agent

**Review baseline:** `b0d740939d9c37d6ba20b58a55ebcd08e7bcdc4d`

## Problem Statement

홈의 자동 배너와 통합 로딩, 스와이프만 가능한 갤러리, 로그인 오류 교정 흐름 때문에 사용자는 원치 않는 전환을 멈추거나 실패한 부분만 복구하기 어렵다. 미리보기의 선택 탭 상태도 시각적으로 구별하기 어렵다.

## Solution

사용자가 홈 콘텐츠와 이미지 탐색을 직접 제어하고 정상 콘텐츠를 계속 사용하며, 로그인 실패에서 입력을 잃지 않고 복구할 수 있게 한다. 앱의 기존 탐색 구조와 브랜드는 유지한다.

## User Stories

1. As a 홈 사용자, I want 배너를 일시정지하는 것, so that 현재 내용을 충분히 읽을 수 있다.
2. As a 홈 사용자, I want 원할 때 배너 자동 재생을 다시 켜는 것, so that 탐색 속도를 스스로 정한다.
3. As a 모션 감소 사용자, I want 자동 전환 없이 배너를 직접 고르는 것, so that 편안하게 콘텐츠를 볼 수 있다.
4. As a 앱 사용자, I want 다른 화면이나 백그라운드에서 배너가 계속 돌지 않는 것, so that 복귀 시 문맥을 잃지 않는다.
5. As a 화면낭독기 사용자, I want 현재 배너와 재생 상태를 안내받는 것, so that 화면을 보지 않아도 제어할 수 있다.
6. As a 홈 사용자, I want 배너 조회가 실패해도 신상품을 보는 것, so that 다른 콘텐츠를 계속 탐색할 수 있다.
7. As a 홈 사용자, I want 실패한 영역만 다시 불러오는 것, so that 정상 콘텐츠가 흔들리지 않는다.
8. As a 네트워크가 불안정한 사용자, I want 로딩·빈 상태·오류의 차이를 아는 것, so that 다음 행동을 고를 수 있다.
9. As a 보틀 사용자, I want 이전/다음 버튼으로 이미지를 바꾸는 것, so that 스와이프 없이도 모든 이미지를 볼 수 있다.
10. As a 보틀 사용자, I want 첫 이미지와 마지막 이미지에서 경계를 아는 것, so that 불필요한 조작을 하지 않는다.
11. As a 화면낭독기 사용자, I want 현재 이미지 번호와 전체 장수를 듣는 것, so that 탐색 위치를 안다.
12. As a 로그인 사용자, I want 비밀번호를 잠시 표시하는 것, so that 입력 오류를 직접 고칠 수 있다.
13. As a 로그인 사용자, I want 오류가 있는 필드와 해결 방법을 안내받는 것, so that 재입력 시행착오를 줄일 수 있다.
14. As a 로그인 사용자, I want 실패 후 이메일과 수정 가능한 입력을 유지하는 것, so that 처음부터 다시 입력하지 않는다.
15. As a 키보드 사용자, I want 다음 필드·제출 순서가 자연스러운 것, so that 화면을 가리지 않고 로그인할 수 있다.
16. As a 비밀번호 관리자 사용자, I want 붙여넣기와 자동완성을 유지하는 것, so that 복잡한 암호를 안전하게 사용할 수 있다.
17. As a 미리보기 사용자, I want 현재 선택 탭을 구분하는 것, so that 앱의 탐색 위치를 이해할 수 있다.
18. As a 앱 사용자, I want 컨트롤을 눌렀을 때 즉시 상태 피드백을 받는 것, so that 조작이 전달됐는지 알 수 있다.

## Implementation Decisions

- M02·M04·M05·M06·L01을 다룬다. 홈의 배너·신상품·영상은 독립적으로 로딩·오류·재시도할 수 있어야 한다. 원래 API 계약과 기존 Query 캐시는 유지한다.
- 배너는 명시적인 재생 상태와 현재 위치를 제공한다. 모션 감소·화면 비활성·앱 백그라운드·사용자 직접 조작에 따른 정지/재개 정책을 한 일관된 상태 계약으로 정의한다.
- 보틀 갤러리는 스와이프와 동등한 이전/다음 제어를 제공한다. 이미지가 0장·1장·여러 장인 상태와 경계에서의 비활성 표시를 정의한다.
- 로그인·이메일 복구의 자동완성·붙여넣기·중복 제출 방지·안전한 복귀 URL 정책을 유지한다. 비밀번호 표시 전환과 오류 연결을 추가하되 인증 요청 횟수나 보안 규칙을 약화하지 않는다.
- 오류는 원인과 다음 행동을 제공한다. 제출 오류 때 적절한 위치로 포커스를 옮기되 매 타이핑·매 blur마다 포커스를 빼앗지 않는다.
- 미리보기 탭의 선택 표현을 네이티브와 의미적으로 맞춘다. 네이티브 탭의 이미 존재하는 selected 상태를 불필요하게 교체하지 않는다.

## Testing Decisions

- 가장 높은 기존 UI→fixture API 사용자 여정으로 검증한다. API 하나의 지연·실패를 제어해 다른 영역의 정상 콘텐츠와 재시도 결과를 관찰한다.
- 배너는 충분한 관찰 구간에서 정지 상태가 유지되고 명시적 재개만 허용되는지 확인한다. 모션 감소·앱 비활성 상태는 실제 플랫폼으로 보완한다.
- 여러 이미지 보틀 fixture를 사용해 버튼과 스와이프의 위치가 일치하는지 확인한다. 포커스를 매번 이동하지 않는 상태 안내도 검증한다.
- 잘못된 이메일·빈 필드·잘못된 비밀번호·네트워크 실패·성공 복귀를 격리된 테스트 계정으로 검증한다. 실제 메일 발송이나 인증 수단 변경은 수행하지 않는다.
- 기존 스크린샷과 카드 경계·렌더링 오류 회귀를 보존한다. 상태 표현 변경은 단순한 클래스명/아이콘 존재 검사가 아니라 사용자에게 보이는 선택·비활성·누름 상태로 확인한다.

## Out of Scope

- 검색 추천·최근 검색 신규 서버 기능
- 실제 이메일 발송·비밀번호 변경·실결제·NICE 인증 완료
- 자동 배너를 제거하거나 브랜드 콘텐츠를 임의의 마케팅 문구로 교체하는 것
