# RN UX 개선 구현 기록

2026-10-18 · 기준 `43c3bd1` 이후 사용자 승인 시안을 반영했다. AI 시안의 샘플 상품·가격·이미지를 실데이터로 대체하지 않았다. 원본 웹의 로고·배경·보틀 이미지를 유지한다.

## 반영한 변화

- 메뉴는 링크를 선택할 때 닫힌다. 내부의 임의 터치 종료로 닫히던 동작을 제거했다.
- 헤더·뒤로가기·검색·시리즈·정렬·배너 제어에 48 단위 조작 영역을 확보했다.
- 필터는 항목별 펼침 목록과 체크박스로 정리했다. 초기화는 스크롤 밖 아래에 두고, 선택 개수를 표시한다. 기존 실시간 필터 적용 정책을 유지한다.
- 시트는 기존 native Modal을 유지한다. 제목 진입·접근성 escape·호출 컨트롤 복귀 및 iOS 키보드 회피를 보완했다. 웹에서는 기존 Modal의 트랩·Escape·복귀를 먼저 검사했다.
- 상품 상세 버튼은 #92400e, 판매중 배지는 #166534로 바꿨다. 실제 렌더링의 흰 글자 대비가 4.5:1 이상이다.
- 보틀 메타 줄 간격을 18로 늘리고 이름 줄 제한을 없앴다. 큰 fontScale에서는 보틀·신상품·상품을 한 열로 보여준다. hero 높이는 콘텐츠에 따라 늘어난다. 기본 375px 분기는 유지했다.
- 홈에 이전/다음·일시정지/재생·위치 표시를 넣었다. 직접 이동 후 정지하며 명시적으로 재개한다. 모션 감소·낭독기·앱/화면 비활성·제어부 키보드 포커스 중 자동 전환을 멈춘다.
- 배너·신상품·영상은 독립적인 Query로 병렬 요청한다. 실패한 영역만 재시도하고 정상 영역은 계속 사용할 수 있다.
- 로그인은 이메일 인라인 오류, 연결된 오류 설명, 비밀번호 표시, 키보드 다음/전송, 거절 후 값 유지·포커스·수정 시 오류 해제를 지원한다. 기존 중복 요청 잠금과 인증 정책을 유지한다.
- 갤러리에 스와이프 외 이전/다음 버튼과 끝 상태를 추가했다. 이미지가 없으면 대체 표시한다.
- 웹 탭의 선택 위치와 헤더·카드의 누름 피드백을 보완했다. native tabs는 유지했다. 보틀 목록·상세의 테두리 기준을 공유한다.
- 글꼴 대기 중 시스템 글꼴의 준비 화면을 표시하고, 4초 이상이면 기본 글꼴로 계속할 수 있다. 글꼴 실패 시에도 탐색을 허용한다.

Playwright는 메뉴 Enter 선택·시트 포커스/닫기/복귀·필터 선택/API/초기화·헤더 크기·로그인 교정·갤러리 버튼·홈 부분 장애·부분 재조회·배너 시간 제어·모션 감소·글꼴 지연/실패·대비를 포함한다. 외부 origin 차단과 pageerror 실패 계약을 유지했다.

Expo SDK 57의 웹 글꼴 로더는 CSS 등록을 준비 상태로 판단할 수 있어 다운로드 지연 중에도 본문을 사용할 수 있었다. 따라서 웹 지연 테스트는 본문 또는 기본 글꼴 계속 동작의 사용 가능성을 확인한다. native의 준비 화면 노출 시간이나 4초 fallback 버튼을 실제 관측한 것으로 해석하지 않는다.

코드 검토에는 React의 독립 요청 병렬화, 효과 정리, 시트 footer/trailing 구성의 ReactNode 조합, 라우트 밖 UI 로직 배치를 적용했다. RN에 Next.js 전용 전환이나 웹 컴포넌트 라이브러리를 추가하지 않았다.

## 남은 작업과 환경

01~06·08~12는 구현 및 웹 검증을 반영했다. 해당 티켓의 native 증거는 대기 상태이며 수용 기준 전체를 완료 처리하지 않았다. 07은 부분 구현이다. 13은 실행 환경 때문에 막혀 있다.

- Android: JDK·SDK·adb·실행 중 에뮬레이터·Maestro가 없다.
- iOS: full Xcode·Maestro가 없다.
- 그래서 VoiceOver/TalkBack, 실제 touch hit testing, Android Back·iOS 키보드, fontScale 1.6/2.0, 백그라운드/포그라운드, 기기 cold-start 5회 전후 측정은 실행하지 않았다.
- GitHub 원격 연결과 Actions 실행도 아직 없다. 기존 runner는 새 `07-design-controls.yaml`을 자동 수집한다. CI 성공이나 native E2E 통과를 주장하지 않는다.

리소스 현재 크기는 NaviSans 6,102,104바이트, Medium 6,104,036바이트, Bold 6,123,840바이트, 합계 18,329,980바이트다. 홈 기본 배경은 7,059,579바이트다. 이번에는 한글/일본어/브랜드 글리프나 OFL 라이선스를 바꾸지 않았으며 서브셋·재인코딩을 하지 않았다. 실제 기기 전후 표본이 없어 시작 속도 개선율·메모리 절감 수치를 만들지 않았다. 이 성능 최적화는 07에 남아 있다.
