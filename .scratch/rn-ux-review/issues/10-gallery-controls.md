# 10: 스와이프 없이도 보틀의 모든 이미지 보기

**What to build:** 사용자는 명시적인 이전/다음 조작 또는 스와이프로 동일한 보틀 이미지들을 탐색하고 현재 위치를 알 수 있다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** medium

**Finding:** M06

**Spec:** S02

- [ ] 이전/다음과 현재 이미지/전체 장수의 의미를 시각·보조기술에 제공한다.
- [ ] 처음·마지막 경계와 0장·1장·여러 장 상태를 처리하고 불필요한 버튼을 활성화하지 않는다.
- [ ] 버튼과 스와이프가 같은 현재 위치를 유지하며 상태 안내가 반복적으로 포커스를 빼앗지 않는다.
- [ ] 여러 이미지 fixture의 보틀 목록→상세→이동→목록 복귀를 검증한다.
- [ ] 기본 이미지 비율·패널 여백·기존 상세 뒤로가기를 유지한다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
