# 04: 상품의 상세 버튼과 판매 상태를 또렷하게 읽기

**What to build:** 사용자는 상품 목록에서 판매 여부·가격·상세 이동을 충분한 대비로 구별하고 올바른 상세에 진입할 수 있다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** high

**Finding:** H04

**Spec:** S01

- [ ] 활성 상세 버튼·판매 배지의 실제 글자/배경 대비가 각각 4.5:1 이상이다.
- [ ] 판매중·품절 텍스트가 색상과 함께 남아 있고 비활성 상태를 활성 상태와 구별할 수 있다.
- [ ] 긴 상품명과 2열 카드에서 배지가 영역 밖으로 밀리거나 가격·상태가 가려지지 않는다.
- [ ] 브랜드의 amber/green 의미를 유지한 전후 캡처와 색 대비 측정값을 기록한다.
- [ ] fixture 상품의 정상/품절/긴 이름 목록→상세 여정을 기존 회귀에서 검증한다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
