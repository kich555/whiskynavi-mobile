# 11: 현재 위치와 누름 상태를 알아보기

**What to build:** 미리보기와 앱에서 사용자는 현재 탐색 위치 및 컨트롤을 누르고 있는 상태를 쉽게 구별할 수 있다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** low

**Finding:** L01

**Spec:** S02

- [ ] 웹 미리보기의 현재 탭이 시각·선택 상태로 구분되며 경로 전환과 일치한다.
- [ ] 네이티브 탭의 기존 selected 스타일과 시스템 탐색 동작을 유지한다.
- [ ] 헤더·카드·직접 누르는 컨트롤의 누름/포커스 피드백이 일관되고 대비를 해치지 않는다.
- [ ] 홈→아카이브→상세→뒤로가기에서 선택 위치와 기존 목록 상태를 회귀 검증한다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
