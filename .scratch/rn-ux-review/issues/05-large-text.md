# 05: 큰 글자로도 보틀과 상품을 비교하기

**What to build:** 글자를 크게 설정한 사용자가 목록에서 보틀명·가격·판매 상태를 읽고 필터와 상세·폼 조작을 완료할 수 있다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** medium

**Finding:** M01

**Spec:** S01

- [ ] 시스템 글자 확대를 전역으로 끄지 않고 1.0·1.6·2.0 배율을 검증한다.
- [ ] 320·390·430 폭에서 필수 가격·상태·버튼이 잘리지 않고 필요한 경우 밀도/줄바꿈을 조정한다.
- [ ] 긴 보틀명은 상세나 확장된 읽기 경로로 전체 확인 가능하며 화면낭독기 레이블도 유지한다.
- [ ] 기본 글자 크기의 웹 동기화 캡처와 네이티브 확대 글자 결과를 별도로 보관한다.
- [ ] 키보드가 열린 입력 흐름에서도 활성 필드와 후속 동작에 접근할 수 있다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
