# 06: 홈 배너를 원하는 속도로 읽기

**What to build:** 사용자는 자동 배너를 멈추거나 재개하고 직접 슬라이드를 골라 연결된 제품이나 페이지를 탐색할 수 있다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** medium

**Finding:** M02

**Spec:** S02

- [ ] 일시정지/재생과 현재 슬라이드 상태가 시각·접근성 이름으로 식별 가능하다.
- [ ] 모션 감소 설정·앱 백그라운드·화면 비활성에서 자동 전환이 정지한다.
- [ ] 직접 슬라이드 선택 후 정지/재개 정책이 일관되며 임의로 빠르게 덮어쓰지 않는다.
- [ ] 각 제어의 유효 터치 영역과 누름 피드백이 확보되고 배너 링크는 정확한 대상으로 한 번 이동한다.
- [ ] 자동 전환 유지/정지/명시적 재개의 시간 기반 여정을 기존 fixture로 검증한다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
