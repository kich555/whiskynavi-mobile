# 08: 홈에서 실패한 콘텐츠만 다시 불러오기

**What to build:** 배너·신상품·영상 중 하나가 실패해도 다른 콘텐츠는 보이고, 사용자는 실패한 영역만 다시 불러와 탐색을 이어간다.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Priority:** medium

**Finding:** M04

**Spec:** S02

- [ ] 배너 실패에서도 정상 신상품을 목록과 상세로 탐색할 수 있다.
- [ ] 신상품 실패에서도 정상 배너·링크가 유지되며 해당 영역에 원인과 재시도를 표시한다.
- [ ] 로딩·빈 상태·오류를 구분하고 재시도가 정상 영역을 지우거나 전체 화면을 다시 막지 않는다.
- [ ] 기존 fixture에서 각 API의 지연·실패·복구를 제어하고 UI→API→콘텐츠 복구를 검증한다.
- [ ] 외부 API 차단·인증 경계와 기존 Query 캐시의 안전한 동작을 보존한다.

**Verification boundary:** 기존 사용자 조작→fixture API→표시 결과의 여정을 사용한다. 스키마·API 변경이 필요 없는 티켓에 가상의 백엔드 작업을 추가하지 않는다. 실제 실행한 검증만 완료 증거로 남긴다.
