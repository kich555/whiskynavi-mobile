## H01 · high · 메뉴가 항목 활성화 대신 touch-end에 의존한다

**관찰/영향:** 브랜드 헤더의 메뉴 내용 전체에 onTouchEnd 닫힘 처리가 있고 링크 자체에 선택 후 닫힘 계약이 없다. RN 미리보기에서 메뉴를 연 뒤 키보드 Enter로 현재 아카이브 항목을 선택해도 메뉴가 남았다. 터치 스크롤 종료에도 닫힐 위험은 코드로 확인되지만 네이티브 재현은 미실행이다.

**코드 근거:** `src/components/native/brand.tsx:70-88` — 위 기준 커밋의 위치이며 리팩터링 이후에는 심볼로 다시 확인한다.

**개선:** 메뉴 안 스크롤·빈 공간 터치와 항목 활성화를 구분하고, 터치·키보드·보조기술의 실제 항목 선택 시 정확히 한 번 이동·닫기한다.

## 확인 범위와 한계

이번에 추가로 한 검증은 소스 리뷰·브라우저 메뉴 재현·터치 크기·색 대비·파일 크기 확인이다. 기존 기준 커밋에는 Playwright 21개, 도메인 테스트 102개, 3플랫폼 번들 내보내기 통과 기록이 있다. 이 리뷰에서 이를 새로 실행했다고 표기하지 않는다. 실제 네이티브 접근성·cold-start·키보드·외부 앱 복귀는 미검증이다. 21개 웹 E2E가 있다는 사실은 이번 발견 항목이 회귀 테스트로 보장된다는 뜻도 아니다.

현재 운영 요청 정리와 외부 제공자 연동의 미해결 이력은 기존 마이그레이션 기록을 따른다. 이번 리뷰는 외부 데이터 수정이나 해당 정리 작업을 수행하지 않았다.

## 판단에 사용한 기준

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): 우선순위·터치·읽기·모션 체크리스트를 사용했다. 검색에서 웹 전용 결과는 네이티브 구현 지시로 채택하지 않았다.

- [WCAG 2.2 Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html): 자동 순환 콘텐츠의 사용자 제어 정책에 참고한다.
